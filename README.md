# COVID-19 Analysis

This project explores COVID-19 case trends using real-world
data from Our World in Data. The goal is to analyse patterns,
identify surges, and visualise key metrics using
Python and pandas.

## Tools Used

- Python (pandas, matplotlib)
- Jupyter Notebook
- Git & GitHub

## Dataset

Source: [Our World in Data - COVID-19](https://ourworldindata.org/covid-deaths)

## Current Focus

- Filtering for country-level data
- Plotting new daily cases and deaths
- Identifying peaks and long-term trends
